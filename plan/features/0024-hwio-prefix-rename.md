# 0024 — Rename the project prefix `hio` → `hwio` / `HWio` / `HWIO_`

- **Status:** In progress
- **Milestone:** GUI feedback follow-up (with 0022)
- **Author:** Matej Strnad
- **Related ADRs:** ADR-0181 (new), ADR-0018 (superseded in part)
- **Depends on:** 0022 (implemented first on the same branch `v2/0022-hwio`, based on `v2/m7-packaging`)

## Context

The user wants the project prefix to read as HARDWARIO more clearly: `hwio` instead of `hio` for the code, the
executables and the environment (ADR-0181). The change is mechanical but touches almost every file, so it is done
once, by a script that can be run again on branches that still use the old names.

## Goals / Non-goals

Goals:
- All names in ADR-0181's table changed in code, build, packaging, CI, tools, tests and live docs.
- Czech translations kept (no new unfinished entries).
- A script `tools/rename-hwio.sh` that does the rename and can be run on another branch before merging it.

Non-goals:
- Backward compatibility with `hio` / `HIO_*` (pre-release).
- Rewriting ADRs and feature plans written before ADR-0181 (history).
- Renaming the GitHub repository, the product name, `com.hardwario.monitor`, Qt organization / application names,
  firmware names, the QML URI `HardwarioMonitor`.

## User experience

Executables `hwio` and `hwio-monitor`; `hwio --version` prints `hwio <version>`; help and error texts that name the
CLI say `hwio`; environment variables `HWIO_*`; packages, icons and desktop entries named `hwio-monitor`. Settings
stay where they are (Qt names unchanged).

## CLI

Executable renamed to `hwio`; commands, options, output and exit codes are unchanged apart from the name in texts.

## Design

`tools/rename-hwio.sh` (bash, GNU sed; run from the repository root on a clean tree):
1. `git mv` every tracked path with the prefix: `libs/**/include/hio/` → `include/hwio/`, `cmake/Hio*` → `cmake/HWio*`,
   `i18n/hio_*.ts` → `i18n/hwio_*.ts`, `*hio-monitor*` → `*hwio-monitor*` (LFS icons keep their LFS pointers).
2. Ordered substitutions over tracked text files, excluding `plan/decisions/`, `plan/features/` (this plan and
   ADR-0181 name the old prefix on purpose), LFS-tracked files and the script itself:
   `hio::` → `hwio::`, `namespace hio` → `namespace hwio`, `hio/` include paths → `hwio/`, `HIO_` → `HWIO_`,
   `Hio[A-Z]` → `HWio[A-Z]`, `hio_` → `hwio_`, `hio-monitor` → `hwio-monitor`, `hio.` log categories → `hwio.`,
   the word `hio` → `hwio`.
3. Protected (masked before step 2, restored after): `hardwario/hio-monitor` (repository URLs), firmware names
   `hio-chester-*` and other `hio-<firmware>` catalog names, `../hio-monitor-*` worktree paths in docs.
4. Translations: both `.ts` files go through the same substitutions, so `<name>hio::…</name>` contexts and source
   texts naming `hio` match the renamed code; `update_translations` afterwards must not add unfinished `cs` entries.
5. Audit: `git grep -n -i -E '\bhio\b|hio[-_:./]|HIO_|Hio[A-Z]'` outside the excluded history may return only the
   protected names above.

After the script: clang-format (include order changes), header-guard / clang-tidy fixes, live docs (`CLAUDE.md`,
`plan/README.md`, `plan/0001-architecture.md`, `plan/0006-cli.md`, README, packaging docs) reviewed by hand.

## Audit whitelist

`git grep -n -i -E '\bhio\b|hio[-_:./]|HIO_|Hio[A-Z]' -- . ':!plan/decisions' ':!plan/features'` after the rename
returns only:

- `hardwario/hio-monitor` — the GitHub repository (update check, release links, metainfo, deb copyright, WiX help
  link, `packaging/RELEASE.md`, CLAUDE.md, tests and test data, the `cs` translation of the releases-page hint).
- `hio-chester-push-fm`, `hio-chester-clime`, `hio-chester-lte-v…` — firmware names (catalog, fixtures, tests).
- `hio-test-console-learning`, `hio-test-console-no-dash-h`, `hio-test-qml-learning` — fake `fw-name` values in
  tests (protected like firmware names).
- `hiomon` — the process name of the old app (v1) in `libs/diag` process scan and its test.
- `hioMockup` — localStorage key of `plan/gui/mockups/index.html`.
- False positives of the case-insensitive pattern: `Melchior` (`cmake/CPM.cmake`), `fashion` (GPL-3.0 text).
- `tools/rename-hwio.sh` itself.

## Risks and open points

- Open branches with old names (`strnad/ci-repair-90059f`) conflict on almost every file: run the script on them
  first, then merge.
- A missed occurrence in a non-built file (CI YAML, packaging scripts) shows only in CI or packaging; the audit grep
  covers tracked files.
